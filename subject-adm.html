MTCSE1203

Advanced Databases and Mining

Normalization, Transactions, Query Optimization, Security, Data Mining & Clustering

5 Units Elective 3 Credits

Course Objectives

  • Deal with data in the real world, maintaining data without redundancy and the techniques in DBMS to handle redundancy.
  • Introduce the multidisciplinary field of data mining, data features, preprocessing, data warehouses and OLAP.
  • Cover the concepts of data clustering such as k-means, k-mediods and DBSCAN, and the role of data mining in web mining.

Course Outcomes

After completing this course, a student will be able to:

  • Analyse normalization techniques.
  • Elaborate on concurrency control techniques and query optimization.
  • Summarise the concepts of data mining, data warehousing and data preprocessing strategies.
  • Apply data mining algorithms.
  • Assess various classification and clustering techniques.
